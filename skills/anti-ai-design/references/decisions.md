# 5つの決定の決め方

実装前にこの5つを言語化する。**「決めていない」項目がそのままAIっぽさになる。**

---

## 1. 色

### 決め方

1. **基準色を1つ**選ぶ。indigo / violet / purple は既定値なので、意図がない限り選ばない
2. その色の**明度違いを3〜5段**用意する
3. **中立色**（背景・境界・文字）を2〜3段用意する。純粋なグレーではなく、基準色をごく僅かに混ぜると馴染む
4. **警告色**（エラー・注意）を1〜2色
5. これ以上増やさない

### 業種から選ぶときの目安

| 印象 | 方向 | 例 |
|---|---|---|
| 事務的・信頼 | 彩度の低い濃紺、鋼色 | 業務システム、金融、医療 |
| 温かい・生活 | 土色、レンガ、深いオレンジ | 個人向け、飲食、教育 |
| 硬質・技術 | 墨、濃灰 + 単色アクセント | 開発者向け、インフラ |
| 高級・静か | 深緑、濃紫紺、生成り | ブランド、不動産、士業 |
| 素朴・親しみ | くすんだ青緑、からし | NPO、地域、小規模事業 |

**迷ったら彩度を落とす。** 鮮やかな色ほど中央値に寄る。

### グラデーション

原則使わない。使う場合は次のどちらかに限る。

- 同系色の微差（明度差20%以内）で、面の奥行きを作るため
- 画像の上に敷く読みやすさ確保のための黒or白の透明度変化

**やらないこと**: 2色以上の色相をまたぐグラデーション、文字へのグラデーション、枠線へのグラデーション。

---

## 2. 文字

### 決め方

**見出し用**と**本文用**を別々に選ぶ。同じ書体で通すなら、ウェイトと字間で明確に差をつける。

| 組み合わせの方向 | 効果 |
|---|---|
| 見出し=セリフ / 本文=サンセリフ | 落ち着き、権威。文章量が多い媒体に合う |
| 見出し=太いサンセリフ / 本文=細いサンセリフ | 現代的。ただし書体選択を誤ると最も中央値に近づく |
| 見出し=等幅 / 本文=サンセリフ | 技術寄り。開発者向けに合う |
| 見出し=和文明朝 / 本文=和文ゴシック | 日本語で最も外さない組み合わせ |

### 日本語のとき

**和文フォントを先に決め、欧文を合わせる。** 逆順にすると、欧文に合わせた行間・字間が和文で破綻する。

- 本文の行間は 1.7〜1.9（欧文の既定 1.5 では詰まって見える）
- 1行の文字数は 35〜45字程度で折り返す
- 見出しの行間は 1.2〜1.4
- 太字は多用しない。和文の太字は面積が大きく、画面が重くなる

---

## 3. 余白

### 決め方

**基準値を1つ決め、その倍数だけを使う。** 4px 基準なら 4/8/12/16/24/32/48/64。中途半端な値（13px, 27px）を混ぜない。

原則:

- **関係の近いものを寄せ、遠いものを離す。** 見出しと本文の間より、セクション間のほうが広い
- 全要素が等間隔だと構造が読めず、テンプレに見える
- 迷ったら**広げる**。詰まった画面は情報量が多く見えるが、実際は読まれない
- 画面端の余白は、要素間の最大余白と同じかそれ以上に

---

## 4. 形（区切り方）

要素の境界を示す方法は**角丸・枠線・影**の3つ。**1つだけ選ぶ。**

| 選択 | 印象 | 注意 |
|---|---|---|
| 枠線のみ | 事務的、明快、軽い | 線の色を薄くしすぎると見えない |
| 影のみ | 柔らかい、浮遊感 | 強い影は古く見える。ごく弱く |
| 角丸 + 背景色の差のみ | 現代的、軽快 | 角丸は 4〜8px に抑える。16px以上はAI的 |
| 何も使わない（余白だけで区切る） | 洗練、静か | 情報密度が高い画面では成立しない |

**3つ全部使うと、それだけでAIが作った画面に見える。**

---

## 5. 主役

画面に**1つだけ**、他と明確に違う扱いの要素を置く。

- ダッシュボードなら、最重要の数字1つを他の3倍の大きさに
- LPなら、製品そのものが分かる図版1つ
- フォームなら、主要な入力欄1つ
- 記事なら、本文そのもの（装飾を全部引く）

**全部が同じ重みだと、情報の優先順位がない = テンプレート、と判定される。**
「何を目立たせるか」より「**何を目立たせないか**」を決めるほうが早い。

---

## 決定の宣言テンプレート

実装前に、この5行を書いてから始める。

```
色: 基準 = {{色}}（{{理由}}）/ 中立3段 / 警告1色 / グラデーションなし
文字: 見出し = {{書体}} / 本文 = {{書体}} / 本文行間 1.8
余白: 基準 8px の倍数のみ / セクション間 64px / 要素間 16px
形: {{枠線 or 影 or 角丸}} のみ使用
主役: {{要素}}（他要素は意図的に弱める）
```
