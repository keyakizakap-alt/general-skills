# 業務資料のレイアウト選択ガイド

判断を求める資料（提案書・経営会議資料・報告書）で、ページごとの構成を選ぶための基準。ここに示す寸法・文字サイズは出発点で、公式の推奨値ではない（経験則・非公式）。実際の会場・ページ数・情報量で調整する。

## 作り始める前の設計表

Web・アプリの画面にも同じ考え方を使うときは、`anti-ai-look` スキルの `references/patterns.md`（資料・Web・アプリを並べた対応表）を見る。このファイルは資料に固有の寸法と文字組みを扱う。


各ページについて「判断してほしいこと／主張1文／根拠／情報の関係／主図／前提・制約」を書く。根拠がない主張をデザインで強く見せない。

| 情報の関係 | 選ぶ構成 | 実装の注意 |
| --- | --- | --- |
| 現状と改善後 | 共通行見出しの左右比較表 | 同じ順序・単位・期間で比較し、変わった工程にだけ色を付ける |
| 複数案の選択 | 評価軸×案の比較表 | 推奨案には選ぶ理由、他案には採用しない条件を添える |
| 数量の大小 | 横棒グラフ | 原則ゼロ基点、直接ラベル、同一縮尺。カードの大きさで数量を示さない |
| 全体と内訳 | 積み上げ棒または内訳表 | 合計と各項目が一致するか確認。費用と効果は同一単位で比較する |
| 増減要因 | ウォーターフォール図 | 開始値・増減・終了値を接続する。時間価値と現金を別系列にする |
| 時間の変化 | 折れ線、必要に応じて目標線 | 月次／累計を混同しない。予測は線種で区別する |
| 手順と承認 | 左から右の業務フロー | 作業担当者をレーンにし、承認・差戻しの分岐を示す |
| 導入の順序 | 月を共通軸にした時間軸 | フェーズ名だけでなく成果物・責任者・判断日を表示する |
| 構成と接続 | 層構造または入出力図 | 既存／新規／人の承認を区別。矢印に対象データや動作を示す |
| 承認依頼 | 決議事項の一覧＋直後の行動 | 金額、対象、執行条件、責任者、期限を明記する |

全部の型を無理に使う必要はない。同じ比較が続くなら表現も揃える。枚数にかかわらず、同じカード配置の使い回しを避けるために全ページの縮小一覧を確認する。

対等な比較は左右5:5、主図と解釈は6:4または7:3を出発点にする。比率を変えても、見出し・本文・脚注の整列線はページ間で共通にする。

## 余白と文字組み

- 16:9を基本とし、左右約5％、上下約5〜7％の安全余白を出発点にする。本文の最大範囲、見出しと脚注の基準線を決める。
- 見出し30〜36pt、本文20〜24pt、図表ラベル16〜20ptを出発点とする。出典は原則12〜14pt以上。サイズだけで判断せずPDFを投影相当の大きさで確認する。
- 判断を左右する制約は本文に置く。脚注だけに書いて読めなくしてはならない。
- 一つの本文ブロックは短い文で3〜5行程度を目安とし、説明が長い場合は別紙またはノートへ移す。法的・数値的な意味を失う省略はしない。
- 日本語は語句の途中、金額と単位の間、固有名詞の途中で意図しない改行がないか確認する。字間を広げすぎない。
- 金額や割合は桁と単位を揃える。表では項目名を左、数値を右へ揃え、縦罫線を増やさない。
- 左右比率を変えても、ページごとに見出しや脚注を無秩序に動かさない。

## 色・写真・強調

- 白地、濃い文字、落ち着いた主色1色が基本。比較の区別や警告に必要なら補助色を追加する。色数の少なさ自体を目的にしない。
- 同じ色に同じ意味を持たせる。色の違いだけで意味を伝えず、ラベル・線種・位置を併用する。
- 一つのページで最も目立つ要素を一つにする。全ての数字を大きくしたり太字にしたりしない。
- 写真は説明する対象と直接関係するものを使う。AIの話題という理由だけでロボットや光る脳を置かない。
- 全面写真を使うときは文字のコントラストと印刷時の可読性を確認する。経営会議の費用・リスク・決議ページでは図表を優先する。
- 動画やアニメーションが動かなくても、PDFの静止画だけで結論が分かる状態にする。
- 見た目の印象を直すときの具体策（余白を飾りで埋めない、左端揃え、配色とコントラスト比、修正指示の出し方）は `anti-ai-look` スキルの `references/fixes.md` にある。

## AI的な定型感を点検する観点

- 全ページに「3項目のカード＋結論帯」が繰り返されていないか。
- 「変革」「最大化」「競争力」など、業務と判断に結び付かない語が見出しを占めていないか。
- 見出しと本文と読み上げ原稿が同じ内容をそのまま反復していないか。
- データのない見栄えだけのグラフや、大きな割合に分母がない表現はないか。
- 直線や箱を取り除いても情報の関係が変わらないなら、その装飾が必要か検討したか。
- 情報量や論点が違うのに、左右の幅と文字の大きさが機械的に同一になっていないか。
- 逆に、見た目を変えるためだけに色・文字・配置が不統一になっていないか。

## 納品前の確認

- [ ] 見出しだけを順に読んで、提案の根拠と承認事項がつながる。
- [ ] 各ページに主張とその根拠があり、試算と実績が分かれる。
- [ ] 0番・ゼロ埋め番号がなく、1から順番になっている（`1 / 9`、`1`、`2`。数量の0は残す）。
- [ ] 図表の軸・単位・対象期間・合計・比較条件が正しい。
- [ ] 現金支出削減と時間価値の区別など、重要な制約が本文で読める。
- [ ] 縮小一覧でレイアウトの反復を確認した。
- [ ] 全ページを1枚ずつ確認し、日本語の崩れ、はみ出し、重なりがない。
- [ ] 画像・フォントの利用条件を確認し、出典を残した。
- [ ] PowerPointの本文・図表が編集可能で、PDF単体でも説明が通じる。
- [ ] 保存先（Gitリポジトリ、共有ドライブ等）への反映を確認してから、取得用リンクを渡した。
