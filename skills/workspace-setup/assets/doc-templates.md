# docs/ai と tasks のひな形

各節を該当ファイルにコピーし、山括弧を埋める。確認できない項目は「未確認」と書く。

---

## docs/ai/context.md

```markdown
# プロジェクト文脈

## 目的
<何のためのプロジェクトか>

## 読者・利用者
<誰が使い、誰が読むか>

## 参照すべき資料
| 資料 | 内容 |
|---|---|
| <パス> | <内容> |

## 確定事項（<日付> に確認）
- <リポジトリや資料で確認できた事実>

## 未確認事項
- <推測や、まだ確かめていないこと>
```

## docs/ai/checks.md

```markdown
# 合格条件と検査

結果は「成功」「失敗」「未実行」で報告する。合格条件を勝手に緩めない。

## 検査コマンド一覧
| コマンド | 対象 | 副作用 |
|---|---|---|
| python3 .claude/hooks/check_setup.py | エージェント用設定の構造 | なし |
| <実在するテスト・Lint・ビルド> | <対象> | <書き出し先など> |

## 作業別の合格条件
### <作業の種類>
- [ ] <判定できる条件>
- [ ] 手動: <人が確認すること>

## 検査スクリプトで判定できないこと
- 指示が実際に守られるか、スキルが適切な場面で起動するか
- 権限ルールが実際に適用されるか（秘密ファイルを開いて試さない）
```

## docs/ai/setup-report.md

```markdown
# 作業環境セットアップ報告
実施日 / 基準コミット / Claude Code バージョン / OS

## 採用した構成
## 既存との関係（重複・統合・保留）
## 変更したファイル
## 実行した検査と結果
## 未適用・未確認（実機確認: /memory /hooks /agents /permissions /context）
## 復元手順（今回の差分だけ。git reset --hard / git clean は使わない）
```
