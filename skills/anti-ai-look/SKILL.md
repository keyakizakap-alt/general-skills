# anti-ai-look

**AIっぽさとは、センスの欠如ではなく「決めなかった箇所が既定値や常套句で埋まった状態」のこと。**
対策は飾りを足すことではなく、作る前に決定を固定し、具体的な情報で埋めること。

## 0. 対象を見分ける

| 対象 | 主に読む資料 | 機械検査 |
|---|---|---|
| UI（Webサイト・LP・アプリ画面・HTML資料） | `references/ui-tells.md`、`references/decisions.md`、`references/stacks.md` | `scripts/check_ui.py` |
| 資料（スライド） | `references/deck-tells.md`（UI と文章の兆候も当てはまる） | HTML は `check_ui.py`、原稿は `check_text.py` |
| 文章（記事・メール・説明文・コピー） | `references/writing-tells.md` | `scripts/check_text.py` |

コードを実行できない環境（claude.ai のチャット等）では、各 `references/*-tells.md` の一覧を目視で当てる。

## 1. 作る前に決める（新しく作るとき）

**UI・資料の見た目**: `assets/design-brief.md` の3項目を先に確定する。書かれていなければ推論して「推定」と明記する（質問で止めない）。

- 参照点: 「〜のような」と言える実例（利用者がすでに使っているサービスや媒体が最良）
- 質感: 形容詞1語（事務的 / 温かい / 硬質 / 静か など）
- 主役: 画面やスライドで最も目立たせる1要素

そのうえで5つの決定（色・文字・余白・形・主役）を固定する（`references/decisions.md`）。要点:

1. 色: 基準色1つ + 中立色2〜3段 + 警告色。indigo / violet / purple を既定で選ばない。色相をまたぐグラデーションを使わない
2. 文字: 見出しと本文の書体を明示的に選ぶ。日本語は和文フォントを先に決める。本文の行間 1.7〜1.9
3. 余白: 基準値1つの倍数だけを使い、関係の近さを間隔の差で示す
4. 形: 角丸・枠線・影のうち、区切りに使うのは1つだけ
5. 主役: 他と明確に違う扱いの要素を1つだけ置く

**文章**: 書き始める前に、伝える相手・結論・その根拠となる数字や事実を書き出す。根拠の無い段落は書かない。

## 2. 作る

- 実データ・実文言を先に入れてから整える（ダミーのまま整えると均質になる）
- 既定値を使わない（フレームワークの既定パレット・既定書体・既定の角丸と影）
- 同じ形を繰り返さない（カード3枚、全セクション中央揃え、全スライド箇条書き）
- 誇張語・万能の形容（革新的、シームレス、包括的、強力な）の代わりに、主語・数字・条件を書く

## 3. 検査する

```bash
python3 scripts/check_ui.py <ファイルまたはディレクトリ>       # .html .css .jsx .tsx .vue など
python3 scripts/check_text.py <ファイルまたはディレクトリ>     # .md .txt .html の本文
```

どちらも「重なりの数」で判定する: 1〜2種類は許容、3〜4種類はテンプレ寄り、5種類以上はAI判定。
検出は語句やクラス名の出現によるので、意図して使っている箇所も拾う。「やめろ」ではなく「意図して選んだか確認しろ」という意味で扱う。

## 4. 「AIっぽい」と言われたときの直し方

全面的に作り直す前に、どこが既定値・常套句なのかを特定する。

1. 検査スクリプトで機械的な兆候を洗う
2. 決めていない項目を特定する（UI なら5つの決定のどれか、文章なら数字・固有名詞・条件が無い文）。たいてい原因はここ
3. 影響が最も大きい1つ（多くは色・余白、文章なら具体性）から直し、他は触らない
4. 直したら再検査し、何が効いたかを報告する

## 報告

```
## AIっぽさの点検: <対象>
- 検査結果: 重なり N 種類（判定）→ 修正後 M 種類
- 決めたこと: 参照点 / 質感 / 主役 / 5つの決定（UI・資料の場合）
- 直したこと: <箇所> — <何を何に変えたか>
- 意図して残したもの: <兆候> — <理由>
- 未確認: <見た目の目視確認ができなかった等>
```

関連: 資料全体の作り方は `deck-sprint`、アプリ全体の進め方は `ryo-product-delivery`。どちらもこのスキルの基準で仕上げを確認できる。
