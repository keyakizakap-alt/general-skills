# 文章の兆候と直し方

「AIが書いた」と感じさせる文章の特徴。UI と同じく、**1つずつは問題にならなくても、重なると確実にそう読まれる。**

> 出典について: ここに挙げる兆候は、生成AIの文章について広く指摘されている特徴を経験則としてまとめたもの（非公式・特定の一次資料なし）。
> 「この語を使ったらAI」という判定基準ではなく、**具体性の欠けた箇所を見つけるための手がかり**として使う。

---

## 根本原因

AIっぽい文章は、**具体的な情報が無い場所を、それらしい言い回しで埋めた**状態。直し方は言い換えではなく、次のどちらか。

1. 具体的な情報（主語・数字・固有名詞・条件・例）を入れる
2. 入れる情報が無いなら、その文ごと削る

---

## 語彙（日本語）

| 兆候 | 例 | 直し方 |
|---|---|---|
| 誇張語 | 革新的、画期的、圧倒的、劇的に、飛躍的に、次世代の、ゲームチェンジャー | 何がどれだけ変わるかを数字か比較で書く。書けなければ削る |
| 万能の形容 | シームレスに、包括的な、網羅的な、強力な、最適な、柔軟な、効率的な | 何と何がつながるのか、何を含むのか、何と比べて速いのかを書く |
| 空疎な抽象 | 様々な、多様な、幅広い、重要な役割を果たす、〜の鍵となる、価値を最大化 | 「様々な」の中身を2〜3個挙げる。挙げられないなら削る |
| 定型の前置き | 〜について解説します、〜を見ていきましょう、本記事では | 削る。いきなり本題に入る |
| 定型の締め | いかがでしたか、参考になれば幸いです、ぜひ試してみてください | 削るか、次に何をすればよいかを具体的に書く |
| 断定回避の連発 | 〜と言えるでしょう、〜と考えられます、〜ではないでしょうか、〜かもしれません | 事実は言い切る。不確かなものは「未確認」「推測」と1回だけ明示する |
| 意味の薄い強調 | 非常に、極めて、大きく、しっかりと | 程度を数字で書くか、削る |

## 語彙（英語）

| 兆候 | 直し方 |
|---|---|
| delve, tapestry, testament, realm, landscape, journey | 具体的な名詞・動詞に置き換える |
| leverage, seamless, robust, cutting-edge, game-changer, unlock, supercharge | 何をどう使うか、何が速くなるかを書く |
| In today's fast-paced world / It's important to note that / Let's dive in | 削る |
| not just X, but Y（多用） | 主張を1つに絞る |
| em dash（—）の多用 | 文を分けるか、カンマ・括弧にする |

## 構造

| 兆候 | 直し方 |
|---|---|
| 太字が段落ごとにある | 太字は1画面に1〜2か所。最も大事な1文だけ |
| 見出しに絵文字（🚀 ✨ 💡 ✅） | 外す。見出しは内容を表す言葉だけにする |
| すべてが箇条書き | 理由や因果は文章で書く。箇条書きは並列の項目・手順だけ |
| 何でも「3つのポイント」 | 実際の数で書く（2つなら2つ、5つなら5つ） |
| 「〜とは？」の見出しが続く | 読者の疑問の順に並べ、見出しは答えの要約にする |
| 同じ文末が3回以上続く（〜です。〜です。〜です。） | 文末を変えるか、文をつなぐ・分ける |
| 各段落が「主張→3つの理由→まとめ」の同じ型 | 型を崩す。結論が1文で済むなら1文で終える |
| 段落の最後に毎回まとめの一文 | 削る。前の文で言えている |
| 内容に関係ない比喩 | 削る |

---

## 直す順番

1. `scripts/check_text.py` で機械的に検出できる兆候を洗い出す
2. **数字・固有名詞・条件が無い文**に印を付ける（ここが本当の原因）
3. 印を付けた文に具体的な情報を足す。足せなければ削る
4. 最後に語彙を直す（語彙だけ言い換えても、具体性が無ければ別の常套句になるだけ）

## 判定の目安

- **兆候1〜2種類**: 気にならない
- **3〜4種類**: 「テンプレっぽい」「AIっぽい」と感じる人が出る
- **5種類以上**: ほぼ確実に「AIが書いた」と読まれる
