# 「AIっぽさ」「安っぽさ」を直す具体策

スライド、Webサイト、アプリの画面、バナー、生成AIで作る画像に共通して使う。見た目の印象を直すときに、どこを、どう変えるかを決めるための基準。

## 1. 空いた場所を飾りで埋めない

- 症状：余白が寂しく見えて、内容に関係のない図形・ぼかしの丸・点模様などを置いてしまう。
- 直し方：内容に関係のない飾りは消す。空いた場所は、余白のまま残す。
- 判断基準：その飾りを消しても、伝わる情報が減らないなら消す。余白が広すぎると感じたら、飾りを足すのではなく、文字や図を大きくするか、要素の間隔を詰める。

## 2. 揃えの基準を左端にし、関連する情報を近づける

- 症状：見出し・本文・ボタンをすべて中央揃えにして、視線の起点が定まらない。関係のない要素が同じ間隔で並ぶ。
- 直し方：
  - 見出し・本文・ボタン・注記の左端を、1本の線に揃える。
  - 関連する情報（見出しとその説明、ラベルとその値）は近づける。グループの中の間隔は、グループどうしの間隔より狭くする。
- 中央揃えを使ってよい場面：表紙や区切りのページの短い1〜2行、単独で置く数字やボタン。3行以上の本文、箇条書き、表の文字は左揃えにする（数値の列は右揃え）。

## 3. 写真・生成画像は「素材の質感」と「光の向き」を残す

- 症状：表面がつるつるで光沢が強すぎる、影がない、どの方向からも均一に光が当たっている。CGのように見える。
- 直し方：過剰な光沢を抑え、素材の質感（陶器の粒、紙の繊維、布の織り目など）を残す。光はやわらかい自然光を一方向から当て、影の向きを1方向にそろえる。
- 画像生成AIへの指示例：「過度な光沢を抑えて素材の質感を出す。やわらかい自然光を左上から当て、影は右下に1方向」。
- 実際の現場・製品・人物と誤解されるおそれがある場面では、生成画像を使わず実物の写真を使うか、生成画像であると明記する。

## 4. 配色は「伝えたい印象」から決め、明暗の差をつける

- 症状：灰色がかった中間色どうしを組み合わせて、全体がぼんやりする。背景と文字の明るさが近く、読みにくい。
- 直し方：
  - 先に伝えたい印象を一言で決め、そこから主色を選ぶ（例：「爽やか」なら青と白）。
  - 本文の文字は濃い色（濃紺、濃い灰色など）にし、背景との明暗の差をはっきりつける。
  - 補足の文字は本文より弱くしてよいが、薄くしすぎない。
- 数値の目安（W3C「WCAG 2.2 達成基準1.4.3」、[解説ページ](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、2026年10月23日確認、公式）：文字と背景のコントラスト比は、通常の文字で4.5:1以上、大きな文字（18pt以上、または14pt以上の太字）で3:1以上。補足や注記の文字も、この基準を下回らないようにする。

## 5. 表現は禁止せず、目的に合わせて使う

- このスキルの「避ける」「使わない」は、目的なく既定値で使うことを指す。グラデーション、中央揃え、アイコン、大きな数字も、目的を説明できるなら使ってよい。
- 判断基準：「その表現を取ると、伝わる情報や印象が減るか」。減るなら残し、減らないなら外す。
  - 例：時間の経過を示すグラデーション、手順の順番を示す番号付きのアイコン、表紙の中央揃え。

## 6. 修正の指示は「場所」と「1項目ずつ」

人に頼むときも、生成AIやデザインツールに指示するときも同じ。

- 「いい感じに」「おしゃれに」「安っぽくなく」ではなく、変える場所と変え方を書く。
  - 悪い例：「もっと洗練された感じにして」
  - 良い例：「本文の背景を白にして、強調色は見出しとボタンだけにする」
- 1回の指示で直すのは1項目だけにする。結果を見てから次の項目に進む。複数をまとめて直すと、どの変更が効いたのか分からず、別の場所が崩れても気づきにくい。
- 直す前と後を、同じ位置・同じ大きさで並べて比べる。
