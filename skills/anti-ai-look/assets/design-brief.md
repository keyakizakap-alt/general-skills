# 設計ブリーフ（実装前に埋める1枚）

これが埋まらないまま実装に入ると、必ず中央値の見た目になる。
**5分で埋める。空欄があるなら推論して埋め、「推定」と明記する。**

```
## 何を作るか
種別: {{LP / ダッシュボード / フォーム / 管理画面 / アプリ画面}}
主要ユースケース: {{誰が、いつ、何のために開くか}}
使用環境: {{PC据え置き / スマホ片手 / 現場で立ったまま / 長時間}}

## 誰が見るか
利用者: {{職種・年齢層・ITの習熟度}}
利用者がすでに使っているもの: {{競合・社内システム・紙}}
  → ここに挙げたものと「見た目が近すぎないか / 遠すぎないか」を最後に確認する

## 参照点（必須・1つ以上）
「{{実在のサービス名 or 媒体}}のような」
ただし {{どこを真似て、どこを変えるか}}

## 質感（形容詞1語）
{{硬質 / 温かい / 事務的 / 高級 / 素朴 / 無骨 / 静か}}
その逆の語: {{避けたい印象}}

## 主役
この画面で最も目立つべき1要素: {{ }}
意図的に弱めるもの: {{ }}

## 制約
ブランド規定: {{あり（指定色・指定書体）/ なし}}
実装環境: {{Tailwind / 素のCSS / 既存デザインシステム}}
画像素材: {{あり / なし}}   ← なしなら、画像を使わない構成を先に決める
アクセシビリティ要件: {{コントラスト比、文字サイズ下限、キーボード操作}}

## 5つの決定（Step 1 の結論をここに書く）
色: 基準 = {{ }} / 中立3段 / 警告1色 / グラデーション {{なし}}
文字: 見出し = {{ }} / 本文 = {{ }} / 本文行間 {{1.8}}
余白: 基準 {{8}}px の倍数のみ / セクション間 {{64}}px
形: {{枠線 / 影 / 角丸}} のいずれか1つのみ
主役: {{ }}
```

## 使い方

- 依頼者に見せて確認するのは「参照点」「質感」「主役」の3つだけでよい。残りは実装側で決める
- 「参照点」が出てこない場合は、**利用者がすでに使っているもの**を聞く。それが最良の参照点になる
- ブランド規定がある場合、このブリーフより規定が優先される
