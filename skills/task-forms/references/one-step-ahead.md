# 一歩先の7種類

「期待以上だった」と感じさせる回答は、依頼の範囲を広げたものではなく、相手の次の一手を短くしたもの。
下から1つ、多くて2つ選ぶ。選ぶ基準は「相手がこの後すぐにすること」。

| 種類 | 何を足すか | 向いている場面 | 例 |
|---|---|---|---|
| 次の質問への先回り | この答えを読んだ人が次に聞くことを1つ予想し、答えておく | 即答、解説 | 料金を答えたら、無料枠の上限と超えたときの挙動も書く |
| そのまま使える形 | コピーして貼れる文面、コマンド、表、設定値 | 文面、手順書、計画 | 「上司に相談を」ではなく、相談のチャット文を書く |
| 前提の誤りやリスクの指摘 | 依頼の前提にある思い込み、期限切れの情報、見落とされた制約 | 比較、企画、原因調査 | 比べている2製品の片方が新規受付を終了している、と先に伝える |
| 判断が変わる条件 | 「〜なら別の選択が良い」を1〜2個 | 比較、判断メモ | 月の利用が1万件を超えるなら従量制より定額が安い |
| 最も強い反対意見 | 推奨に対する、いちばん手強い反論とそれへの答え | 判断メモ、企画、応募文 | 「既存の表計算で足りるのでは」に数字で答える |
| 捨てた選択肢と理由 | 検討したが採らなかったものを一言ずつ | 比較、アイデア出し、計画 | 候補から外した3つと、外した理由 |
| 実際に確かめた結果 | 計算、実行、検索で確かめた結果そのもの | 原因調査、データ、手順書 | 「動くはず」ではなく、実行した出力を貼る |

## 守ること

- 足したものが本題より長くならない。目安は全体の2割以内
- 依頼されていない成果物を作らない（「ついでに資料も作りました」をしない）。作ったほうが良いと考えたら、提案として1行で書く
- 指摘は事実に基づける。確かめていない懸念は「未確認」と書く
- 相手の決定事項を蒸し返さない。すでに決めたことの是非ではなく、決めた先で役に立つものを足す

## 選び方の例

| 依頼 | 選ぶもの | 理由 |
|---|---|---|
| 「AとBどっちがいい？」 | 判断が変わる条件 | 相手の状況を全部は知らないので、自分で当てはめられる形にする |
| 「お断りのメールを書いて」 | そのまま使える形（相手との関係に合わせた1案。件名に代案を入れる） | 送る直前の作業を無くす |
| 「このエラーの原因は？」 | 実際に確かめた結果 | 推測の一覧より、1つ確かめた事実のほうが進む |
| 「新サービスの企画を考えて」 | 最も強い反対意見 | 通す場で必ず聞かれる |
| 「来月の試験の勉強計画」 | 次の質問への先回り（遅れたときの削り方） | 計画は必ず遅れる |
