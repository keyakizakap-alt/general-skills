description: 作業を区切り、次のセッション（別のチャット・別のエージェント）が続きから始められる状態にする
---

次の順で実行する。

1. 検証コマンド（`.claude/harness.json` の `check`）を実行し、結果を確認する。
2. `PROGRESS.md` を更新する。
   - 「進行中」: 今の状態を事実だけで（何が動いて、何が未完か）
   - 「次にやること」: 次のセッションが最初にやる具体的な1〜3手
   - 「完了」: 今回終えたものを日付つきで1行ずつ。古い項目は要約して短く保つ
3. 設計判断をした場合は `docs/decisions/NNNN-<slug>.md` に残す。
4. 最後に、更新内容と検証結果を3行以内で報告する。
