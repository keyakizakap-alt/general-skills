# 日本語の文章（Markdown を書くとき）

- 普通の日本語で、具体的に書く。比喩、誇張、宣伝文句（「革命的」「最強」「完璧」など）を使わない。
- 1文1主張を基本にし、結論を先に書く。表と箇条書きは比較・手順に限って使う。
- 数字・仕様・機能ステータス（Preview / GA / 非推奨など）には出典URLと参照日を付ける。出典が無いものは「未確認」と書く。
- 日時・通貨・単位・税込/税別は依頼や元資料の指定に合わせる。指定が無い時差換算や税計算はしない。
- コード識別子、コマンド、ファイル名、製品の正式名称はバッククォートで囲み、原文どおりに書く。
- 仕上げに `python3 skills/anti-ai-look/scripts/check_text.py <ファイル>` で常套句・太字の多用・同じ文末の連続を確認する（兆候を説明している文書では誤検出がある）。
- 表記は既存ファイルに合わせる（例: 文末は「である調」の体言止め・常体が中心）。
