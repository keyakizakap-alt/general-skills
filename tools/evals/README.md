# スキルの効果を測る

スキルあり・なしで同じ依頼に答えさせ、どちらがスキルありかを伏せて採点する。スキルを直したら、ここで測ってから「良くなった」と言う。

```bash
python3 tools/evals/run_eval.py task-forms --out /tmp/eval-run            # 全件
python3 tools/evals/run_eval.py task-forms --out /tmp/eval-run --only 9,12 # 一部
```

- `claude` CLI が必要。実行のたびに API の利用が発生する（依頼1件につき生成2回・採点2回）。CI では実行しない
- 出力先はリポジトリの外にする
- 測るのはスキルの中身の効果で、スキルが自動で起動するかは測らない
- 採点者も同じ系統のモデルで、人の評価の代わりにはならない

## 依頼セット

| スキル | 場所 | 件数 |
|---|---|---|
| `task-forms` | `task-forms/prompts/` | 12（1〜8: 比較、断りメール、原因調査、企画、解説、学習計画、障害報告、アイデア出し / 9〜12: 即答、議事録、データの読み取り、応募文） |

## 依頼を足すとき

- 実際に受けた依頼に近い文面で、1ファイル1依頼（`prompts/<番号>.txt`）
- 変わりうる事実の確認が要らないもの（検索なしで答えられるもの）
- 個人名・社名・顧客情報など実在の情報を入れない
